# Casos de Estudio con Vectores

## Descripción

Este repositorio contiene el desarrollo de tres casos de estudio realizados para la asignatura **Técnica de Programación**. Los ejercicios fueron desarrollados utilizando vectores y estructuras de control para el procesamiento y análisis de datos en diferentes escenarios reales.

El objetivo de la práctica es aplicar conceptos de programación relacionados con arreglos, ciclos, acumuladores y cálculos estadísticos básicos, permitiendo resolver problemas mediante el almacenamiento y procesamiento de información.

## Casos de estudio desarrollados

### Caso 1: Ventas de Abarrotes

Aplicación que registra las ventas de diferentes categorías de productos y calcula:

* Categorías con ventas superiores al promedio.
* Categorías con ventas críticas.
* Porcentaje de participación de cada categoría respecto al total de ventas.

### Caso 2: Servicios de Clínica Dental

Aplicación que registra la cantidad de atenciones por especialidad y determina:

* Especialidades superiores al promedio.
* Especialidades con demanda crítica.
* Porcentaje de participación de cada especialidad respecto al total de atenciones.

### Caso 3: Envíos de Mensajería

Aplicación que registra la cantidad de envíos por zona geográfica y permite obtener:

* Zonas superiores al promedio.
* Zonas con servicio crítico.
* Porcentaje de participación de cada zona respecto al total de envíos.

## Tecnologías utilizadas

* Java
* Programación orientada a eventos
* Vectores (Arrays)
* Estructuras de control
* Operaciones matemáticas y estadísticas básicas
